# UW5 Mini-Shop

Klickbarer Mini-Shop ohne Backend (LF10a, UW 5, Projekt 1).

- Listenansicht der Produkte
- Detailmodal pro Produkt

## Starten

`index.html` im Browser öffnen, z. B. mit der VS-Code-Erweiterung *Live Server*.

## Arbeitsweise

Die Aufgaben werden als 5 Issues im GitHub-Project **LF10MiniShop** geplant. Pro Ticket ein Branch und ein Pull Request, der mit der Review-Checkliste geprüft wird.
